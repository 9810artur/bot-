# LocalAdsBot

Маркетплейс рекламы между бизнесом и блогерами на Telegram.

## Описание проекта

LocalAdsBot — это Telegram-бот, который объединяет бизнес и блогеров:

- **Бизнес** публикует рекламные кампании
- **Блогеры** получают уведомления и подают заявки
- **Бизнес** выбирает блогеров для сотрудничества

## Технологический стек

- **Python 3.12** — основной язык
- **Aiogram 3.x** — фреймворк для Telegram Bot API
- **PostgreSQL** — база данных
- **SQLAlchemy 2.x** — ORM
- **Alembic** — управление миграциями БД
- **Docker & Docker Compose** — контейнеризация
- **Python-dotenv** — управление переменными окружения
- **Pydantic** — валидация данных

## Функциональность

### Для блогеров 📱

- ✅ Регистрация и создание профиля
- ✅ Заполнение анкеты (нишу, количество подписчиков, ссылки на соцсети)
- ✅ Просмотр доступных рекламных кампаний
- ✅ Подача заявок на участие в кампаниях
- ✅ Просмотр своих заявок и их статусов

### Для бизнеса 💼

- ✅ Регистрация как рекламодатель
- ✅ Создание рекламных кампаний
- ✅ Просмотр своих кампаний
- ✅ Просмотр заявок от блогеров
- ✅ Принятие или отклонение заявок

## Установка

### Требования

- Docker и Docker Compose
- Python 3.12+ (для локальной разработки)
- PostgreSQL (используется в контейнере)

### Быстрый старт с Docker

1. **Клонируйте репозиторий:**

```bash
git clone https://github.com/9810artur/bot-.git
cd bot-
```

2. **Создайте файл .env:**

```bash
cp .env.example .env
```

3. **Отредактируйте .env и добавьте BOT_TOKEN:**

```bash
nano .env
```

Убедитесь, что поле `BOT_TOKEN` содержит ваш токен от BotFather.

4. **Запустите Docker Compose:**

```bash
docker-compose up -d
```

Приложение автоматически:
- Создаст базу данных
- Применит миграции
- Запустит бота

5. **Проверьте логи:**

```bash
docker-compose logs -f app
```

### Локальная разработка

1. **Создайте виртуальное окружение:**

```bash
python -m venv venv
source venv/bin/activate  # На Windows: venv\Scripts\activate
```

2. **Установите зависимости:**

```bash
pip install -r requirements.txt
```

3. **Запустите PostgreSQL:**

Вы можете использовать Docker для PostgreSQL:

```bash
docker run --name postgres -e POSTGRES_PASSWORD=postgres -p 5432:5432 -d postgres:16-alpine
```

4. **Примените миграции:**

```bash
alembic upgrade head
```

5. **Запустите бота:**

```bash
python -m src.main
```

## Использование

### Команды для пользователя

- `/start` — начать работу с ботом
- `/profile` — просмотреть профиль
- `/help` — справка по командам
- `/influencer` — меню блогера
- `/advertiser` — меню рекламодателя
- `/settings` — настройки
- `/admin` — панель администратора (только для админов)

### Основной сценарий

#### Для блогера:

1. Нажмите `/start`
2. Выберите роль "Блогер"
3. Заполните профиль
4. Нажмите "Просмотр кампаний"
5. Выберите интересующую кампанию
6. Подайте заявку
7. Ожидайте решения рекламодателя

#### Для рекламодателя:

1. Нажмите `/start`
2. Выберите роль "Бизнес"
3. Нажмите "Создать кампанию"
4. Заполните детали кампании
5. Нажмите "Мои кампании"
6. Просмотрите заявки от блогеров
7. Примите или отклоните заявки

## Структура базы данных

### Таблицы

#### users
- `id` — первичный ключ
- `telegram_id` — уникальный ID Telegram
- `role` — роль (advertiser, influencer, admin)
- `full_name` — полное имя
- `username` — username
- `city` — город
- `created_at` — дата создания

#### influencer_profiles
- `id` — первичный ключ
- `user_id` — ссылка на пользователя
- `niche` — ниша (область деятельности)
- `followers_count` — количество подписчиков
- `instagram_link` — ссылка на Instagram
- `tiktok_link` — ссылка на TikTok
- `telegram_link` — ссылка на Telegram
- `advertising_price` — цена за одну рекламу

#### campaigns
- `id` — первичный ключ
- `advertiser_id` — ID рекламодателя
- `title` — название кампании
- `description` — описание
- `city` — город для кампании
- `budget` — бюджет
- `required_influencers` — количество нужных блогеров
- `campaign_date` — дата проведения
- `status` — статус (draft, active, paused, completed, cancelled)
- `created_at` — дата создания

#### applications
- `id` — первичный ключ
- `campaign_id` — ID кампании
- `influencer_id` — ID блогера
- `status` — статус (pending, accepted, rejected, completed, cancelled)
- `created_at` — дата создания

## Миграции базы данных

### Создание новой миграции

```bash
alembic revision --autogenerate -m "описание изменения"
```

### Применение миграций

```bash
alembic upgrade head
```

### Откат на предыдущую версию

```bash
alembic downgrade -1
```

## Логирование

Логирование настроено в `src/config/logging_config.py`:

- Логи выводятся в консоль и файл `logs/app.log`
- Уровень логирования устанавливается переменной `LOG_LEVEL`
- Файлы логов ротируются при размере 10 MB
