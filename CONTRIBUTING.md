"""Contributing guidelines for LocalAdsBot."""

# Вклад в LocalAdsBot

Спасибо за интерес к нашему проекту! Мы рады приветствовать вклады от сообщества.

## Как начать

1. Создайте fork репозитория
2. Клонируйте ваш fork: `git clone https://github.com/your-username/bot-.git`
3. Создайте ветку для вашего изменения: `git checkout -b feature/описание`
4. Сделайте изменения
5. Запушьте в ваш fork: `git push origin feature/описание`
6. Откройте Pull Request в основной репозиторий

## Правила кода

### Стиль кода

- Используйте **Black** для форматирования
- Следуйте **PEP 8**
- Максимальная длина строки: 88 символов
- Используйте type hints везде, где это возможно

### Коммиты

```
type(scope): краткое описание

Дополнительное описание если необходимо.

Примеры:
feat(auth): добавить авторизацию через Telegram
fix(handlers): исправить ошибку в регистрации
docs: обновить README
refactor(services): переименовать методы
```

### Ветки

- `feat/описание` — новые функции
- `fix/описание` — исправления
- `docs/описание` — документация
- `refactor/описание` — рефакторинг
- `test/описание` — тесты

## Требования к Pull Request

- Описание должно четко объяснять изменения
- Код должен быть протестирован
- Все тесты должны проходить
- Соответствовать стилю кода проекта
- Добавить тесты для новой функциональности
- Обновить документацию если необходимо

## Процесс проверки

1. Минимум один одобряющий review
2. Все check должны пройти
3. Нет конфликтов с основной веткой
4. Код соответствует стилю проекта

## Вопросы или проблемы?

Откройте Issue с детальным описанием:
- Что вы пытались сделать
- Что произошло
- Чего вы ожидали
- Версии (Python, aiogram и т.д.)
- Шаги для воспроизведения
